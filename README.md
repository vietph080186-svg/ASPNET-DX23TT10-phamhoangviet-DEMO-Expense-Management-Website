## Giới thiệu đề tài
Dự án xây dựng hệ thống quản lý chi tiêu nhằm giúp người dùng theo dõi, phân loại và báo cáo các khoản chi hàng ngày.

Dự án quản lý chi tiêu cá nhân và doanh nghiệp với các chức năng theo dõi, báo cáo và quản lý ngân sách.

## Hướng dẫn cài đặt
1. Clone repository về máy:
```bash
git clone https://github.com/vietph080186-svg/ASPNET-DX23TT10-phamhoangviet-DEMO-Expense-Management-Website.git
```
2. Mở Visual Studio và chọn `ExpenseManagement.sln`.
3. Chọn cấu hình `Debug` và kiểm tra các tham chiếu.

## Hướng dẫn chạy project
1. Mở `ExpenseManagement.sln` trong Visual Studio.
2. Đặt `ExpenseManagement.Web` làm Startup Project.
3. Chạy project với IIS Express hoặc Local IIS.

## Trạng thái hiện tại của dự án
Đã khởi tạo cấu trúc thư mục ban đầu và tạo solution/project ASP.NET Web Forms.
